# 4단계 — 모방학습

## 목표

보상 없이 **시연(demonstration) 데이터만으로** 정책을 학습시키고, 그 방식의 강점과 한계를 직접 겪는다.
최근 피지컬 AI(ACT, Diffusion Policy, VLA 등)의 바탕이 이 방식이다.

## 핵심 개념

- **Behavior Cloning(BC)**: "이 관측에서 전문가는 이 행동을 했다"를 지도학습으로 따라 하기
- **분포 이동(distribution shift)**: 작은 실수가 쌓여 시연에 없던 상태로 가면 회복을 못 하는 문제
- **DAgger**: 정책이 간 상태에서 전문가에게 다시 물어 데이터를 보강하는 방법
- **Action chunking**: 한 스텝이 아니라 여러 스텝 행동을 한 번에 예측 (ACT 등)

## 세션 과제

코드는 `py/il/` 아래. 3단계의 팔 환경을 그대로 쓴다.

- [ ] **S1. 전문가 데이터 수집**
  3단계에서 학습한 PPO 정책(또는 2단계의 역기구학 제어기)을 "전문가"로 두고 시연 에피소드 N개 수집.
  (관측, 행동) 쌍을 파일로 저장하는 포맷을 직접 정한다.
- [ ] **S2. BC 직접 구현**
  PyTorch로 작은 MLP를 만들어 관측 → 행동 지도학습. 라이브러리 없이 학습 루프 작성.
  성공률을 전문가와 비교.
- [ ] **S3. 한계 확인**
  시연 개수를 줄이고(예: 100 → 10), 실행 중 행동에 노이즈를 넣어 성공률 변화 관찰.
  실패 영상을 보고 "어디서부터 무너지는지" 기록.
- [ ] **S4. DAgger**
  BC 정책으로 돌면서 방문한 상태에 전문가 행동을 라벨링해 데이터 추가 → 재학습. S3과 비교.
- [ ] **S5. 사람 시연**
  키보드로 팔을 조종하는 텔레옵 스크립트를 만들어 직접 시연 데이터 수집 → BC 학습.
  전문가 정책 데이터와 비교해 무엇이 다른지 (일관성, 속도, 노이즈) 기록.
- [ ] **S6. 현재 도구 살펴보기**
  LeRobot 같은 오픈소스 프레임워크의 데이터셋 포맷과 정책(ACT, Diffusion Policy 등)을 살펴보고,
  제공되는 시뮬 예제 하나를 CPU로 짧게 학습·평가.
  **이 영역은 변화가 빠르므로 이 시점의 최신 문서 기준으로 진행.**

## 완료 기준

- 시연 데이터만으로 학습한 정책이 작업을 수행한다 (성공률 기록).
- S3·S4 결과로 분포 이동과 그 해결 방법을 설명할 수 있다.

## 자가 점검 질문

1. BC와 3단계 RL의 차이를 "무엇으로부터 배우는가" 관점에서 설명하면?
2. BC 학습 손실은 낮은데 실제 성공률이 낮은 이유는?
3. 사람 시연이 전문가 정책 시연보다 학습이 어려울 수 있는 이유는?
4. Action chunking이 분포 이동 문제에 왜 도움이 될 수 있나?
5. GPU가 있었다면 이 단계에서 무엇이 달라졌을까? 지금 범위에서 놓치는 건?
