# 6단계 — 사전학습 모델 다루기 (선택)

## 목표

남이 대규모로 사전학습한 피지컬 AI 모델(VLA 등)을 불러와서 **내 로봇에 맞게 연결하고, 미세조정하고, ROS2로 돌리는** 흐름을 한 번 끝까지 해본다.
4단계(모방학습)와 5단계(통합)를 큰 모델로 다시 하는 것. 개념은 같고 규모와 도구가 다르다.

**선행 조건:** 4단계 S6(영상 관측 정책), 5단계 완료

## 이 단계의 전제

- 추론은 CPU(Steam Deck)로 시도한다. 실용적인 속도가 나오는 모델이 있는지는 **이 단계 시작 시점에 확인 필요**.
- 미세조정은 GPU가 필요하다. 이 단계에서만 클라우드 GPU를 짧게 빌린다.
- 모델·프레임워크가 매우 빠르게 바뀌는 영역이므로 아래 과제는 "무엇을 할지"만 정하고, 구체적인 모델은 그때 고른다.

## 세션 과제

코드는 `py/pretrained/` 아래.

- [ ] **S1. 모델 조사**
  공개된 사전학습 정책·VLA 모델을 3개 이상 조사해 표로 정리:
  파라미터 수, 입력(카메라 수·해상도, 언어 지시, 관절 상태), 출력(행동 형식, action chunk 길이), 라이선스, CPU 추론 가능 여부.
  하나를 고르고 이유를 기록.
- [ ] **S2. CPU 추론**
  고른 모델을 제공 예제 데이터로 추론만 돌려본다.
  1회 추론 시간, 메모리 사용량을 측정하고 5단계의 제어 주기와 비교.
- [ ] **S3. 내 로봇에 연결 (zero-shot)**
  내 MuJoCo 팔의 관측을 모델 입력 형식으로 변환(이미지 크기·정규화, 관절 차원 맞추기)하고,
  모델 출력을 내 팔의 관절 명령으로 매핑. 미세조정 없이 돌려본다.
  잘 안 될 가능성이 높다 — **왜 안 되는지**를 기록하는 게 목적.
- [ ] **S4. 데이터 준비**
  4단계 방식으로 영상 + 관절 + (언어 지시) 시연 데이터를 모으고, 모델 프레임워크의 데이터셋 포맷으로 변환.
  변환 스크립트에 검증(프레임 수, 시각 정렬, 값 범위) 포함.
- [ ] **S5. 클라우드 GPU 미세조정**
  GPU를 짧게 빌려 미세조정. 소요 시간·비용·사용한 설정을 기록하고 체크포인트를 받아온다.
  S3(zero-shot)과 성공률 비교.
- [ ] **S6. ROS2 노드로 실행**
  5단계 정책 노드에 미세조정한 모델을 끼운다.
  추론이 제어 주기보다 느릴 때 action chunk로 어떻게 메우는지 구현하고 확인.
  CPU로 감당이 안 되면 "추론 서버는 따로, ROS2 노드는 네트워크로 요청"하는 구조를 설계해본다.

## 완료 기준

- 미세조정한 사전학습 모델이 ROS2를 통해 시뮬레이터 속 내 팔을 제어한다.
- zero-shot → 미세조정 사이의 성능 차이와 그 이유를 설명할 수 있다.

## 자가 점검 질문

1. 사전학습 모델이 내 로봇에서 바로 동작하지 않는 이유를 입력·출력·물리 관점에서 꼽으면?
2. 미세조정에 필요한 시연 수가 4단계의 BC보다 적거나 많다면, 그 이유는?
3. 추론 1회에 500ms가 걸리는 모델로 50Hz 제어를 하려면 어떻게 해야 하나? 그 방법의 대가는?
4. 언어 지시를 바꿨을 때 행동이 달라지는가? 달라지지 않는다면 무엇을 의심해야 하나?
5. 이 단계에서 내가 직접 이해하고 다룬 부분과, 블랙박스로 둔 부분은 각각 무엇인가?
