# ROS2-Practice

ROS2와 피지컬 AI를 혼자 연습하기 위한 단계별 과제 모음.

## 최종 목표

> **시뮬레이션 속 로봇팔이 내가 학습시킨 AI 정책으로 작업을 수행하고, 그 정책이 ROS2 노드로 동작한다.**

## 전제

| 항목 | 내용 |
|---|---|
| 배경 | ROS1 + Python 개발 경험 (약 2년 전), AI 에이전트로 작업하는 데 익숙함 |
| 주 환경 | Steam Deck (SteamOS) — 준비 완료 |
| 보조 환경 | Mac (MuJoCo·Python 학습 코드), Ubuntu PC (GPU 없음, Gazebo 대체용) |
| GPU | 없음 → Isaac Sim은 범위 밖. 1~5단계는 CPU로 진행, 6단계 미세조정만 클라우드 GPU |
| 시간 | 들쭉날쭉 → 주차가 아니라 **세션(약 1시간) 단위**로 쪼개 둠 |

## 단계

| 단계 | 주제 | 완료 기준 |
|---|---|---|
| [1](stages/01-ros2-basics/) | ROS1 → ROS2 복구 | 노드·토픽·서비스·launch를 직접 짜고 ROS1과의 차이를 설명 |
| [2](stages/02-sim-robot/) | 시뮬 속 로봇 | 직접 만든 로봇팔을 Gazebo에 띄워 ROS2로 관절 제어 |
| [3](stages/03-rl-basics/) | 강화학습 기초 | MuJoCo에서 reaching 학습, 보상 설계가 결과를 바꾸는 이유 설명 |
| [4](stages/04-imitation-learning/) | 모방학습 | 시연 데이터만으로 학습한 정책이 작업 수행 (영상 관측 포함) |
| [5](stages/05-integration/) | 통합 | 학습한 정책을 ROS2 노드로 감싸 시뮬 로봇 제어 **(최종 목표)** |
| [6](stages/06-pretrained-models/) | 사전학습 모델 (선택) | 미세조정한 사전학습 모델(VLA 등)이 ROS2로 내 팔을 제어 |

1~2단계는 ROS2, 3~4단계는 피지컬 AI를 각각 다루고 5단계에서 합쳐진다.
3·4단계를 2단계와 병행해도 된다 (MuJoCo 쪽은 Mac에서도 가능).
6단계는 실제로 쓰이는 대형 모델을 다뤄보는 단계로, 미세조정에만 클라우드 GPU가 필요하다.

## 진행 규칙

1. **AI가 코드를 짜도 된다.** 단, 세션이 끝나면 두 가지를 확인한다.
   - AI 없이 그 코드의 일부를 고칠 수 있는가
   - 왜 그렇게 동작하는지 설명할 수 있는가
2. 각 단계의 **자가 점검 질문**에 AI 없이 답하지 못하면 다음 단계로 넘어가지 않는다.
3. 세션마다 [기록 템플릿](templates/session-log.md)으로 `logs/`에 남긴다. 특히 "막힌 지점"과 "틀렸던 예상"을 적는다.
4. 버전·도구는 빠르게 바뀐다. 각 단계 시작 시 공식 문서에서 현재 상태를 확인한다.

## 폴더 구조

```
stages/      단계별 과제 설명
ws/src/      ROS2 패키지 (colcon 워크스페이스, ws/에서 colcon build)
py/          ROS와 무관한 Python 코드 (MuJoCo, 학습 스크립트)
logs/        세션 기록
templates/   기록 템플릿
```
